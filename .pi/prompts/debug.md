# Debug

Investigate the reported problem before making changes.

Follow this process:

1. Reproduce the problem when possible.
2. Inspect the relevant code, logs, errors, and tests.
3. Identify the most likely root cause.
4. Distinguish the root cause from symptoms.
5. Explain the evidence supporting the diagnosis.
6. Propose the smallest appropriate fix.
7. Identify possible side effects or regressions.

Do not modify files yet.

Your response should include:

- Observed behavior
- Expected behavior
- Evidence
- Root cause or leading hypothesis
- Proposed fix
- How the fix should be verified

If the evidence is insufficient, say what additional information or experiment is needed instead of guessing.
